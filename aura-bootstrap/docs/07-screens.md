# 07. 화면 구성 (와이어프레임 + rev08 조정)

원본: `docs/wireframe.pdf` (연구자 초기 와이어프레임). 와이어프레임의 배치·디자인은 자유롭게 바꿀 수 있다. **명세와 다른 부분은 이 문서의 "rev08 조정"이 우선**한다. 이 문서는 수직 슬라이스 단계부터 사용한다.

## 화면 목록과 조정 사항

| # | 화면 | 와이어프레임 | rev08 조정 |
|---|---|---|---|
| S0 | 연구자 시작 | 참가자 번호 입력 + "시작" | 연구자 패스코드, participant_code, is_pilot 토글 추가. 참가자에게 넘기기 전 화면 |
| S1 | 연구 설명문 | PDF 임베드 + "다음" | 그대로 (PDF는 플레이스홀더) |
| S2 | 동의서 | PDF 임베드 + 동의함/동의하지 않음 | 그대로. 거절 시 종료 화면, 이후 수집 중단 |
| S3 | 기본 정보 | 나이, 성별(여성/남성), 교육 수준, AI 사용 경험 | **성별에 "응답하지 않음" 추가**(rev08 요구). 교육 수준 범주는 와이어프레임 채택. AI 사용 경험 범주는 미정(docs/00) |
| S4 | PPD | 15문항, 5점 | 중간 라벨은 "보통"이 아니라 **"동의하지도 반대하지도 않음"**(docs/03). 기본 선택값 없음 |
| — | (배정) | 없음 | 화면 없음. S4 제출 시 서버가 배정하고 바로 S5로. 처치 문구 노출 금지 |
| S5 | 역할 배정 과제 n 상황 안내 | 시나리오 + "다음" | 제목은 "과제 1/2"만. Low/High를 드러내는 표현 금지. 원문 + 공통 응답 안내 |
| S6 | 상황 인식 설문 | Risk MC | docs/03 §2의 3문항, 7점 |
| S7 | 직원 정보 확인 | 12명 카드 그리드(4×3) + 타이머 | 카드 클릭 시 확대(열람 이벤트 기록). **선정 기준 열람 버튼** 추가. Round 2 와이어프레임에 빠진 "다음" 버튼 추가 |
| S8 | 첫 번째 판단 | 기준 목록 + 직원 1명 카드 + ←/→ + 진행 수 + 배정함/배정하지 않음 | **버튼 문구를 "적격"/"부적격"으로 변경**(rev08은 배정 여부가 아니라 적격성 판단, 인원 제한 없음). 아이콘+문구 유지(색만으로 구분 금지). ←/→로 잠금 전 검토 가능. "완료"는 12개 응답 후에만 확정, 미응답 시 위치 안내. 확정 확인 다이얼로그 후 잠금 |
| S9a | (AI 대기) | 없음 | **10초 중립 대기 화면 추가**("추천 준비 중"). 모든 조건 동일 |
| S9 | AI 추천 정보 확인 | 카드 5개 + "AI 답변에 오류가 있을 수 있습니다." | **12명 전원**의 AURA 판정(적격/부적격)을 표시(와이어프레임의 5개는 구 설계). 권위 배지·안내문 + 공통 안내문(docs/01)으로 교체 — 와이어프레임 문구는 쓰지 않는다. 명칭은 "AI"가 아닌 "AURA". 설명 영역은 조건별(none/fi/fi_case), 영역 높이는 조건 간 고정 |
| S10 | 최종 판단 | S8과 동일 구조 | **초기 판단을 읽기 전용으로 표시** + 해당 직원의 AURA 판정·설명 재열람 경로 추가. 새 선택은 비어 있는 상태에서 시작(자동 선택 금지). 순서는 S8과 동일 |
| S11 | 판단 경험 설문 | S-TIAS | docs/03 §3, 7점 |
| — | Round 2 | S5~S11 반복 | 남은 맥락으로 반복 |
| S12 | 마무리 설문 | 조작 확인, 정확도, UMUX-LITE, 자유 응답 | 순서: 권위 확인 → 설명 확인 → 지각된 정확도 → UMUX-LITE → 자유 응답(선택) |
| S13 | 종료 | 감사 문구 + "종료" | 그대로. 이후 뒤로 가기로 재진입 불가 |

## 타이머 표시 원칙
- 와이어프레임의 타이머는 유지하되 **예정 시간 안내용**이다. 0이 되어도 화면을 막거나 자동 제출하지 않는다.
- 0 이후에는 초과 상태를 조용히 표시(예: 경과 시간)하고 `overtime_start` 이벤트를 기록한다. 경고음·빨간 점멸 등 압박 연출은 쓰지 않는다.
- 표시 방식은 모든 조건에서 동일하다.

## 공통 레이아웃 원칙
- 상단: 화면 제목(좌), 타이머(우). 하단 우측: 진행 버튼. 모든 화면 동일 위치.
- S8/S10의 좌측 상단 기준 목록은 선정 기준 요약으로 사용하고, 전체 문구는 "선정 기준 보기"로 연다.
- S9와 S10에서 AI 패널의 위치·크기는 조건과 무관하게 고정한다.
