# 04. 의존 행동 지표 (rev08 §2, §7 정확도 오차)

플랫폼의 책임: 아래 지표를 **원자료에서 재산출 가능하게** 저장하고, 서버에서 참가자×라운드별 분자·분모를 계산해 함께 저장한다. 계산값만 저장하고 원자료를 버리지 않는다.

## 기호
프로필 단위로 I(초기 판단), A(AI 판단), F(최종 판단), G(정답)를 기록한다. 모두 1=적격, 0=부적격. 무응답은 `null`(0이 아님).

## 핵심 지표 (참가자×라운드)
```
RAIR = n(I ≠ G, A = G, F = G) / n(I ≠ G, A = G)
RSR  = n(I = G, A ≠ G, F = G) / n(I = G, A ≠ G)
```
| 초기 | AI | 최종 | 해석 |
|---|---|---|---|
| 오답 | 정답 | 정답으로 변경 | RAIR 분자 포함 |
| 오답 | 정답 | 오답 유지 | 해당 기회 과소의존 |
| 정답 | 오답 | 정답 유지 | RSR 분자 포함 |
| 정답 | 오답 | AI 오답으로 변경 | 해당 기회 과도의존 |
| 정답 | 정답 | 유지/변경 | 두 주 지표에서 제외, 보조 지표에 포함 |
| 오답 | 오답 | 유지/변경 | 두 주 지표에서 제외, 보조 지표에 포함 |

- 분모가 0이면 비율은 `NA`(0이나 1로 채우지 않음). 사유 코드로 "기회 없음"과 "기술적 결측/무응답"을 구분한다.
- 1−RAIR, 1−RSR은 같은 기회 집합 안에서만 과소/과도의존율로 해석한다.
- RAIR와 RSR을 평균·합산한 단일 지수를 만들지 않는다.
- 한 지표의 분모가 0이어도 다른 지표와 신뢰 자료를 삭제하지 않는다.

## 보조 지표
| 지표 | 계산 |
|---|---|
| 최종 AI 일치율 | n(F=A) / 유효 판단 수 |
| 초기 정확도 / 최종 정확도 | n(I=G)/N, n(F=G)/N (같은 유효 프로필 집합) |
| AI 방향 전환율 | n(I≠A, F=A) / n(I≠A) |
| 정확도 변화 | 최종 정확도 − 초기 정확도 |

## 저장 필드 (round_metrics, 참가자×라운드 1행)
`rair_num, rair_den, rair (nullable), rair_na_reason, rsr_num, rsr_den, rsr (nullable), rsr_na_reason, final_ai_agree_num/den, init_acc_num/den, final_acc_num/den, switch_to_ai_num/den, n_valid, metrics_version`
- 비율은 분석 시 재계산 가능하도록 분자·분모를 정수로 저장한다.
- "유효 판단"은 I와 F가 모두 null이 아닌 프로필이다. AI 노출 기록이 없는 프로필은 유효에서 제외하고 사유를 남긴다.

## 지각된 정확도 오차
```
정확도 추정 오차(pp) = PERC_ACC − 100 × (16/24)
```
실제 정확도는 정확한 비율 2/3을 사용한다(66.7 상수 금지). 예: 85 → +18.3pp, 55 → −11.7pp. "모름"은 NA.

## 측정 코드의 필수 테스트 케이스
1. 초기 오답 → AI 정답 → 최종 정답: RAIR 기회 1, 분자 1.
2. 초기 정답 → AI 오답 → 최종 오답: RSR 기회 1, 분자 0.
3. I = A인 프로필은 RAIR·RSR 어느 분모에도 들어가지 않는다.
4. 8개 이진 (I, A, G) 조합 × 두 가지 최종 선택(F=0/1) = 16가지 전부 검증.
5. 기회가 하나도 없는 참가자 → 두 비율 NA, 사유 "no_opportunity".
6. 일부 프로필 기술적 누락 → 유효 집합에서 제외, 사유 기록.
7. 재접속·재전송으로 인한 중복 이벤트 → 중복 제거 후 결과 불변.
