# 03. 측정 도구 (rev08 §7, §8)

공통 규칙
- 문구·순서·척도는 이 문서 그대로 사용한다. 임의로 다듬지 않는다.
- 응답에 기본 선택값을 두지 않는다. 무응답은 `null`이며 0으로 채우지 않는다.
- 원응답(`item_id`, `raw_response`, `scale_version`, `missing_reason`)과 파생 점수를 분리 저장한다. 파생 점수는 분석 코드에서 재산출 가능해야 한다.
- 차원명·척도명은 연구자용이다. 응답 화면에 평가적 안내로 쓰지 않는다.

## 1. 사전 PPD (Adamovic, 2023) — 동의·인구통계 직후, 조건 배정 전
- 15문항, 5점: 1=전혀 동의하지 않음, 2=동의하지 않음, 3=동의하지도 반대하지도 않음, 4=동의함, 5=매우 동의함
- 모두 정방향(역채점 없음). 문항 순서는 아래 순서로 고정, 모든 참가자 동일 위치·동일 안내문.
- scale_version: `PPD-ko-rev08`

| item_id | 문항 |
|---|---|
| PWR1 | 관리자는 부하 직원과 상의하지 않고 대부분의 의사결정을 스스로 내려야 한다. |
| PWR2 | 관리자는 직원들의 의견을 가급적 묻지 않는 것이 좋다. |
| PWR3 | 관리자가 부하 직원을 대할 때 권위와 권력을 사용하는 것이 필요한 경우가 많다. |
| CON1 | 낮은 직급의 사람은 높은 직급의 사람의 요청을 이의 없이 따라야 한다. |
| CON2 | 나는 어른과 의견이 다를 때, 젊은 사람이 연장자의 뜻을 따라야 한다고 생각한다. |
| CON3 | 직원은 경영진의 결정에 이견을 제기하면 안 된다. |
| HIE1 | 명확한 보고 체계는 나에게 매우 중요하다. |
| HIE2 | 분명한 지휘 체계는 나에게 매우 중요하다. |
| HIE3 | 확실한 권한 체계는 나에게 매우 중요하다. |
| PRE1 | 존경을 받는 것은 내 삶의 지침이 되는 중요한 가치이다. |
| PRE2 | 사회적 지위를 얻는 것은 나에게 매우 중요하다. |
| PRE3 | 다른 사람들이 나를 우러러보는 것은 나에게 매우 중요하다. |
| SOC1 | 관리자는 업무 외적으로 직원들과 사적인 교류를 하지 않아야 한다. |
| SOC2 | 나는 권력을 가진 위치에 있는 사람은 자신보다 권력이 적은 사람들과 거리를 두려고 노력해야 한다고 생각한다. |
| SOC3 | 조직은 고위 관리자를 위한 별도의 시설(예: 전용 식사 공간)을 마련해야 한다고 생각한다. |

점수(분석 코드): 차원별 3문항 완결 시 평균, 15문항 완결 시 전체 평균. 하나라도 결측이면 해당 점수 NA. 저장 전 1~5 정수 검증.

## 2. Risk 조작 확인 — 각 라운드 시나리오 직후 (두 맥락 동일 형식·시점)
7점: 1=전혀 동의하지 않음 ~ 7=매우 동의함. scale_version: `RMC-rev08`

| item_id | 문항 |
|---|---|
| RMC_SEV | 이 배정이 부적합하면 그 결과가 중대할 것이다. |
| RMC_REV | 배정이 확정된 뒤 역할을 변경하기 어려울 것이다. |
| RMC_RES | 이 시나리오에서 최종 배정 결정의 책임은 나에게 귀속될 것이다. |

## 3. 라운드별 신뢰 S-TIAS (McGrath et al., 2025) — 각 라운드 최종 판단 직후
"방금 경험한 AURA"에 대한 신뢰. 7점: 1=전혀 그렇지 않다 ~ 7=매우 그렇다. 모두 정방향. scale_version: `STIAS-ko-rev08`

| item_id | 문항 |
|---|---|
| TRUST_CONF | 나는 AURA에 확신이 있다. |
| TRUST_REL | AURA는 신뢰할 만하다. |
| TRUST_TRU | 나는 AURA를 신뢰할 수 있다. |

점수: 세 문항 완결 시 평균, 일부 결측이면 NA.
